# Testing
- `cargo build --release && cargo test --release` : Rust unit tests (+ `core/tests/mlp_lite.rs`: parity with ONNX Runtime golden outputs and a mutation fuzz of the mlp-lite parser) (routing tokenizer, softmax, semver, plan validation).
- `python3 -m pytest tests -q` : acceptance tests driving the real Rust binary (178 Python tests collected, 175 run by default; 3 are optional: the real-OpenClaw contract test needs `OPENCLAW_BIN`, the two Kotlin-suite runs need `RUN_ANDROID_JVM_TESTS=1`; incl. tests/test_phase10.py, tests/test_backends.py, tests/test_phase9.py, tests/test_phase8.py, tests/test_graph.py, tests/test_phase5.py, tests/test_phase6.py, tests/test_phase7.py: activation order, corruption, tamper, untrusted signer, incompatibility variants, failed tests, dependencies, version/rollback, NEEDS_HELP, unload/reload, store tampering, teacher isolation, LearningPackage validation).
- `python3 scripts/run_phase9.py && python3 scripts/summarize9.py` : real-world tasks (needs `pip install scikit-learn`); `python3 scripts/novelty_rules.py` : offline novelty-rule comparison.
- `python3 scripts/run_phase8.py && python3 scripts/summarize8.py` : policy/OpenClaw/research/containment (benchmarks/reports/phase8.*). `OPENCLAW_BIN=/path/to/openclaw.mjs python3 -m pytest tests/test_phase8.py -k real_openclaw` runs the real-binary contract test.
- `python3 scripts/run_phase7.py && python3 scripts/summarize7.py` : consolidation + routing comparison + cross-phase baselines (benchmarks/reports/phase7.*).
- `python3 scripts/run_phase6.py && python3 scripts/summarize6.py` : selective learning, provider path, fault matrix (benchmarks/reports/phase6.*).
- `python3 scripts/run_phase5.py && python3 scripts/summarize5.py` : detection ablation + escalation (benchmarks/reports/phase5.*).
- `python3 scripts/run_phase4.py && python3 scripts/summarize4.py` : composition experiment (benchmarks/reports/phase4.*).
- `python3 scripts/run_phase3.py && python3 scripts/summarize.py` : the sequential-learning experiment; writes `benchmarks/reports/phase3.json` and `.md`.
Requirements: Rust 1.97+, Python 3.11, `pip install numpy onnx onnxruntime torch cryptography pytest`.
- `LITE=0|1 ./scripts/run_android_jvm_tests.sh` : builds the host JNI library (full, or lite = no tract), generates fixtures and runs the 14 Kotlin bridge tests with Gradle (needs JDK 17+, Gradle, Maven Central); `RUN_ANDROID_JVM_TESTS=1 python3 -m pytest tests/test_phase10.py` runs both variants.
- `python3 scripts/android_targets_check.py && python3 scripts/summarize10.py` : compile-level Android target builds (needs `pip install ziglang` and `rustup target add` for the three Android targets); `python3 scripts/backend_bench.py` : mlp-lite vs tract.
